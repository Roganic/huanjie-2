# 账号接入选择（2026-09-09）

首个 Sites 测试版本采用平台登录与稳定用户 ID，沿用现有服务端身份隔离及云端存档，无需再购买账号服务。它要求访客能够使用平台登录，不等于任意邮箱都能在游戏内注册。2026-09-09 已实际发布为所有者私有网站；用户完成 ChatGPT 登录后进入角色创建，创建角色与切换短篇已写入云端。实际新页面已从云端恢复角色、通关记录、对话和工坊草稿；不同真实账号之间的端到端测试未开展，隔离规则与并发保存已由服务端检查覆盖。

匿名请求与伪造客户端用户头均返回 401。Sites 测试访问凭证只通过站点访问层，没有实际用户 ID，因此同样不能读写游戏存档；没有为自动化验证放宽身份检查。真实登录后的请求由平台注入身份，保存接口正常工作。

若后续需要脱离平台、开放独立注册，可接入免费档身份服务，无需目前自行维护密码系统。

| 方案 | 已查证范围 | 接入判断 |
| --- | --- | --- |
| Sites 平台身份 | 当前 Sites 技能认证文档提供受信任的用户 ID/邮箱头、登录与退出入口；私有站点要求登录 | 最少新增依赖，适合本次 Sites 交付。服务端必须检查身份，不接受客户端自报用户 ID；所有者真实登录和云端恢复已验证。 |
| Supabase Auth | 官方 Free 档含 50,000 月活跃用户 | 可支持独立账号，但需要创建项目、配置登录方式和凭据。免费额度不意味着邮件投递等周边服务没有限制。 |
| Clerk | 官方 Hobby 档含 50,000 月留存用户，计数方式与 MAU 不同 | 可接入独立登录界面，也需要创建应用及配置域名/凭据。 |

本轮未注册任何外部账号、购买套餐或声称第三方登录已完成。网站账号功能与模型 API 预算分开，免费身份档不覆盖模型调用费。
