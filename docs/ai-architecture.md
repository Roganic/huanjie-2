## 权威边界

- AI 理解玩家意图、选择允许的工具、组织人物回应与氛围描述。
- 模组定义场景、人物知识与条件、可执行互动、任务和奖励。
- 规则服务检查目标/资源/阶段，负责检定、伤害、状态、成长与奖励。
- 会话与存档保存事实和交流记录；模型对白不能成为资源变化的依据。
- 页面显示真实裁定及 AI 补充回应，失败时明确反馈。

## 一轮主持

读取会话快照 → 提供当前能力与有限上下文 → AI 最多两次只读查询 → 选择一项行动或追问 → 核对状态版本 → 统一命令执行并保存回执 → AI 根据已保存结果回应 → 校验和记录回应 → 等待玩家。

模型网络调用不持有全局游戏锁。每轮最多 4 次模型调用，1 次游戏操作。回执在叙事前保存，断线重放不会再次结算。

## 代码位置

| 位置 | 职责 |
| --- | --- |
| `src/gm/provider.py` | 服务端配置、兼容工具调用、错误隔离 |
| `src/gm/context.py` | 当前能力目录、场景查询、人物知识过滤 |
| `src/gm/host.py` | 有界主持循环、状态版本验证、回执及记忆 |
| `src/game/commands.py` | 统一执行、回滚、防重复结算与事实变化 |
| `src/content/schema.py` | 模组、人物知识及解锁条件，编辑器/解析器共同边界 |
| `src/state.py`、`src/game_state.py` | 会话与完整存档 |
| `src/routers/action.py` | 网页命令、SSE 适配、主持状态 |

旧 `src/agent/` 内含历史固定分支编排、叙事与规则检查兼容接口；不把其类名当作自主 Agent 的证据。新网页主持不调用旧编排器，必要规则验证复用。
