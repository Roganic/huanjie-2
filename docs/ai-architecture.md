# AI 系统架构

阅读顺序：先看“当前原则”和“核心模块”，只有在开始实现某个模块时再向下展开。

本文件用于定义 AI 跑团系统的正式架构边界。

## 当前原则

- 使用本地 Web 作为第一版交互载体
- 模型负责叙事、角色表现和内容生成
- 规则引擎负责骰子、数值和状态裁定
- 记忆系统负责摘要、状态保持和检索
- 系统编排层负责在不同模块之间分发任务

## 核心模块

- GM agent
- 规则引擎
- 记忆 / RAG
- 会话状态
- 前端交互层

## 待细化

- GM agent 输入输出协议
- 会话状态结构
- 规则调用流程
- 长对话摘要策略
- 模型选型与成本策略
