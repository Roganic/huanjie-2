# AI 系统架构

阅读顺序：先看“当前原则”和“核心模块”，只有在开始实现某个模块时再向下展开。

本文件用于定义 AI 跑团系统的正式架构边界。

## 当前原则

- 使用本地 Web 作为第一版交互载体
- 模型负责叙事、角色表现和内容生成
- 规则引擎负责骰子、数值和状态裁定
- 记忆系统负责摘要、状态保持和检索
- 系统编排层负责在不同模块之间分发任务

## 核心模块

- GM agent
- 规则引擎
- 记忆 / RAG
- 会话状态
- 前端交互层

## 后端模块规划

当前 `app/backend/src/` 只有入口和健康检查。后续按需新增：

| 目录 | 职责 | 对应核心模块 |
|------|------|-------------|
| `routers/` | HTTP 接口层 | 前端交互层 |
| `engine/` | 骰子、数值、状态裁定 | 规则引擎 |
| `agent/` | GM 提示词编排、模型调用 | GM agent |
| `memory/` | 摘要、状态持久化、检索 | 记忆 / RAG |
| `models/` | 共享数据结构 | 会话状态 |

原则：目录不提前建，有实际代码时再创建。
