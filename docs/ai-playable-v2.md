## 本轮交付

- **询问和执行分开**：常见问路、位置和权限问题只提供只读工具。去已经到达的地点不会变成交谈。明确向在场 NPC 提问及连续追问，必须先通过真实交谈服务；模型不能直接编造对白绕过线索、事件和委托。
- **行动范围明确**：每轮把可选行动 ID 放入工具参数枚举，执行时再次验证。NPC 提问只允许对应交谈；模型无权制造额外操作。人物知识条件、友方保护、每轮一次行动的规则保持有效。
- **当前事实完整**：行动后的主持可见当前位置、在场人物、当前指引、已知线索和战斗参与者/当前回合，避免因为缺少信息编造人物去向。NPC 使用近期同人物对话；读档恢复一致。
- **叙事与规则分层展示**：显示玩家输入与 AI 回应，原始裁定可展开查看；检定仍直接显示。地图和背包按钮的 AI 回应不再被丢弃。战斗中的说明性回答也会展示。
- **描述校验与降级**：拦截明显物品交接、成长、裁定成败矛盾和错误下一行动者；最多在原有预算内重写一次对白，不重新执行行动。仍不合格时显示原因和已保存的规则结果。
- **模型设置页**：可选择兼容服务类型、填写地址/模型、测试并保存、启用/关闭 AI。可直接粘贴以 `/v1` 结尾的地址。测试采用真实 respond 工具调用，不触碰冒险状态；草稿测试不自动保存。
- **密钥边界**：后端本地文件原子写入、权限 0600、Git 忽略；读取设置只返回是否已保存密钥。留空保留密钥；更换服务地址必须填对应密钥。环境变量覆盖时明确禁止无效保存。设置接口只接受本机来源，异常不回传密钥或供应商原始正文。
- **等待与恢复**：所有游戏按钮共用一个请求编号和完整结果接收。网络中断、服务器异常或响应不完整时保存原请求，刷新后仍可“恢复上次结果”；已执行的行动从回执读取，不重复移动、掷骰或扣物品。恢复前阻止新游戏操作，并禁用读档/重置等切换入口。没有逐 token 直播，等待状态如实显示处理耗时。
- **用量**：设置页显示当前冒险最近最多 40 轮的模型调用、已返回的输入/输出 tokens、中位和 95% 耗时、降级回合数。该窗口会随存档恢复，不是账户账单；连接测试单独显示用量，服务商未返回的用量不在统计中。

## 验收证据

后端 701 项通过（7 条既有依赖弃用警告）；前端构建、lint 和 3 项有实际故障情形的命令恢复测试通过。新增后端检查集中于设置密钥保护、来源限制、询问权限、NPC 工具限制、用量不重复、叙事重写和当前回合校验。

真实模型 `qwen3.7-flash-2026-07-15` 的完整抽样使用临时会话/存档和固定验收骰点，模型调用为真实请求，生产骰点未修改。覆盖：

1. 当前场景指引、老马库斯消息、问路不移动、抵达入口及重复目的地不行动。
2. 托尔金委托与连续追问，手动存档、清除会话内存后读档继续对话。
3. 自由表达映射石门调查、取得巡逻记录、回村示警、领取一次奖励和持久结局。
4. 委托奖励不重复；示警后通道内仍有三名敌人。
5. 全体敌人进入先攻、防御、攻击、胜利结算和返回探索。
6. 每轮重放相同编号，断言状态与回合计数不变。

浏览器独立冒险验证了设置页布局、留空保留密钥、保存提示、真实连接测试（0.6 秒，输入 331 / 输出 37 tokens）、聊天与裁定展示、恢复历史和近期用量。主动停止验收后端后提交移动，再启动、刷新、恢复原请求，最终只移动一次，场景时间从 0 变为 1。未操作用户原冒险。

## 运行与复验

- 游戏顶部“模型设置”保存后，下次行动生效；原角色和存档无需重建。新增 NPC 人物设定仍属于内容 1.2.0，旧冒险保留原内容快照。
- 后端运行 `scripts/check_gm.py` 做一次纯连接验证。
- 后端运行 `.venv/bin/python scripts/accept_gm.py --live` 执行独立真实流程；最多 32 轮，默认报告 `/tmp/huanjie-gm-acceptance.json`。该命令会消耗模型额度，不属于普通 pytest。流程允许“行动正确完成但错误对白被拦截”的安全降级，会统计并保留原因，不把它计作 AI 回应成功。
- 前端执行 `node --test tests/gameApi.test.ts` 验证中断、错误、完整响应和刷新后恢复，使用支持 TypeScript 的 Node 运行时（本地 Node 26 已验证）。

## 仍然明确的边界

自由语言仍可能出现措辞、姓名简称或不够准确的推断；关键词和结构校验不能证明任意对白正确。状态、奖励、敌人和任务以规则记录为准。低成本模型未通过校验时允许使用固定结果继续游戏，不宣称所有回合都达到高质量文学叙事。

恢复功能用于取回既有结果，不会对已结算行动重新生成一次结果；服务中断在保存之后、对白完成之前时，可能取回带“回应尚未完成”提示的固定裁定。多设备共享配置、远程模型管理、跨设备请求恢复和长期账户成本统计尚未包含。
