# 基础游戏 V1

> 当前规则更新（2026-09-07）：友方/中立攻击暂时禁用；此前已有的敌对存档保留。地图已升级为透明方格浮窗，当前全量 671 项通过。以下原版本记录中的主动攻击和平人物/新达成敌对结局不再是当前可用入口，详见 [地图与友方保护](floating-map.md)。

目标：交付一个无需模型即可完整试玩、可保存继续、供后续 AI 主持接入的文字 RPG 基础版本。本轮按整个版本交付，内部任务连续推进。

## 版本范围与完成门槛

1. 内容、会话事实、命令执行、结果呈现有明确边界；网页输入不直接调用旧 AI 编排器，规则不依赖前端组件。
2. 三职业支持 1–5 级；探索、任务选择、敌对、战斗、恢复、失败和存档组成真实闭环。所有检定都有内容或规则来源。
3. 样例冒险有引导、调查/冲突、分支结果和持久结局；完成任务带来实际成长，不以任意刷经验作为验收。
4. 首批持续状态为中毒（攻击/技能劣势，经过 3 个有效行动解除）与鼓舞（下一次攻击/检定优势）；与佯攻/防御正确抵消。中毒可通过解毒剂或长休解除。非法行动不推进状态。
5. 新版冒险在村庄/酒馆可免费长休；野外长休消耗一份营地补给。初始补给与可拾取补给由内容配置，旧内容默认不增加成本。短休仍使用生命骰；不引入饥饿、负重、复杂经济。
6. 主界面聚焦场景、可用行动和叙事，角色/资源与结局清楚可见，重复信息收起；不展示尚未接通的模型选择。
7. 核对产品能力矩阵和真实玩家路径：三职业双路线、资源耗尽/恢复、非法行动、敌对后果、升级、结局和读档。全量回归及前端检查通过，完成隔离浏览器试玩。

## 明确裁剪与后置

当前是单人、固定内容、无空间距离的文字 RPG。只支持配置的场景行动和现有职业技能，不实现完整原版职业体系、任意社交裁定、实时画布引擎、模型叙事、RAG、编辑器或自然语言模组解析器。后续模块复用内容 Schema、命令和事实结果接口。

旧会话固定内容快照，不热升级也不重置用户进度。新版通过独立新冒险启用。工程验收完成不等于趣味性和 AI 主持质量已获产品验证。

## 命令与内容接口

网页玩法统一调用 `POST /commands`，携带 `X-Session-Id`。示例：

```json
{"kind":"move","target_id":"dungeon-entrance-01","request_id":"本次逻辑操作唯一编号","expected_scene_id":"tavern-01"}
```

命令类型为文字、移动、拾取、装备/卸下、使用、休息、攻击、战斗行动和离开战斗。统一返回 `result`（原有结构化裁定）、`changes`（变化的事实分组及前后值）、`state`（最新展示状态）、`request_id`、`replayed`。可选 `expected_scene_id` 拒绝旧场景操作；同一请求编号重试返回原裁定，不再次掷骰/扣资源/发奖励。编号绑定完整请求内容，复用给不同操作返回 409；每个会话保留最近 64 份回执。

JSON 是完整契约；SSE 是网页叙事适配层，发送 start/chunk/complete，complete 保留原裁定、变化与重放标记。旧 HTTP 操作路径继续兼容，但请求幂等和事务边界以 `/commands` 为准。失败操作回滚会话事实与历史；自动存档在完整命令结束后写入，每个冒险滚动一份，手动存档保持独立。存档写入先生成临时文件再替换，避免半份 JSON 覆盖有效文件。

内置内容升级为 **1.1.0**。Schema 增加 `endings`、`supplies`、场景 `safe_rest`、任务 `xp_reward`、互动 `advantage_flags/success_condition/failure_condition`。全部有兼容默认值；旧内容与旧会话不会自动增加消耗。结局在首次满足条件时记录等级、经验、地点、线索和时间，继续探索只改变当前世界，不重写历史结局。

首个样例提供“重开的通道”“及时的警告”“破裂的信任”三种结果。清场奖励 150 XP；完成任一路线委托再获得 300 XP 和两瓶药水。无需修改测试内容奖励，三职业都能通过任务自然升至 2 级。结局不是强制结束，玩家仍可继续探索其他地点。

## 玩家入口

打开本地网页，进入 **模组 → 内置冒险 → 以最新内容开始新冒险**，加载 1.1.0。原冒险、角色与存档保留；读取旧存档继续使用旧内容。建议先与老马库斯交谈并阅读行路笔记，再找托尔金选择调查或战斗路线。
