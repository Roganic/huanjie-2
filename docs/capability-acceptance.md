“通过”均指 V1 已选定范围；涉及扩展的边界列在同一行。

| 编号 | 能力 | 当前结果与证据 | 范围边界 |
| --- | --- | --- | --- |
| B01 | 人物与属性 | 通过。三职业创建、属性/装备/生命派生值及非法输入回归通过；页面分配标准数组可自动交换，提交采用已展示的数值 | 标准数组、随机预览、手动属性；不含种族和完整构筑系统 |
| B02 | 技能与豁免检定 | 通过。场景配置决定技能、难度、成本和成败后果；法术使用既有攻击/豁免规则；普通交谈无检定 | 不支持未配置的特殊社交、任意动作或任意难度覆盖 |
| B03 | 优势/劣势 | 通过。鼓舞、碑文线索、中毒和佯攻共同参与裁定；双骰取高/低、抵消和一次性消耗有路径验证 | 不叠加层数；不扩展完整原版状态表 |
| B04 | 地图与探索 | 通过。7 地点、合法相邻移动、互动解锁、线索、清场/示警双路线及一次性事件可保存恢复 | 地点图；不含站位、距离、警戒和察觉机制 |
| B05 | 背包与装备 | 通过。拾取、叠放、装备、卸下、治疗和解毒共用服务；满血可解毒，无需治疗/解毒时不消耗 | 效果限已支持类型；不含商店、负重或任意脚本 |
| B06 | 战斗 | 通过。全敌人参战、固定先攻、主/附赠动作、自动敌方回合、技能成本、撤退、胜败和奖励闭环 | 先攻 d20 + 敏捷修正；不含空间战斗 |
| B07 | 状态与失败 | 通过。中毒持续 3 个有效行动，鼓舞作用于下一次攻击/检定；解毒剂和长休可解毒。零生命统一失败并提供读档/新冒险 | 不含复活、濒死豁免和完整原版异常状态 |
| B08 | 职业与成长 | 通过。战士、盗贼、法师的既有能力与 1–5 级派生资源一致；战斗和任务共用 XP/升级服务。三职业都能通过真实任务升到 2 级 | 5 级上限；不含技能树和完整原版职业能力 |
| B09 | 时间与恢复 | 通过。行动推进统一时间及状态；野外长休消耗 1 份补给，村庄/酒馆免费；无补给/战斗/失败状态拒绝休息。短休使用生命骰 | 沿用抽象时间；旧内容未启用补给时保持原规则 |
| B10 | 保存继续 | 通过。完整快照包含内容、战斗、任务、结局、状态时长和命令回执；自动存档每个冒险滚动一份，手动存档独立保留；异常操作可回滚 | 旧内容快照不热升级；原有存档不删除 |
| B11 | 完整试玩 | 通过。三职业清场和示警路线均有 API 验收；实际浏览器走通示警升级、补给耗尽、三敌人胜利、结局保留和手动读档 | 工程闭环通过；趣味性、平衡和长篇叙事质量仍待玩家验证 |

## 接口与状态边界

| 编号 | 当前结果 | 后续复用方式 |
| --- | --- | --- |
| I01 行动入口 | 通过。网页文字、移动、物品、休息、攻击/战斗全部发送 `/commands`；兼容路径调用同一服务 | 新呈现层直接提交命令，无需复刻规则 |
| I02 可用行动 | 通过。探索目标/前置条件/检定提示、战斗可用能力、休息资源与拒绝原因由后端提供，执行时再次校验 | 编辑器配置内容；客户端只展示当前投影 |
| I03 裁定结果 | 通过。命令返回 `result/changes/state/request_id/replayed`；检定、伤害、成本和事件保持结构化 | 后续 AI 叙事和动画读取已结算事实，不从叙事反推数值 |
| I04 权威状态 | 通过。会话保存唯一运行事实，战斗缓存由快照恢复；命令在会话锁内执行，异常回滚，回执避免相同请求重复结算 | 回执保留最近 64 个编号；一次性奖励另外由任务/事件进度保护 |
| I05 内容与呈现 | 通过。内容包统一故事、人物、物品、地图、事件、任务、结局及补给定义；标识稳定，规则不依赖 DOM | `StoryParser → ModulePack` 草稿边界及 Schema 保留；编辑器/文本解析器继续后置 |

## 验收证据

后端全量、前端构建/lint 和浏览器结果以 [版本验收记录](base-game-v1.md#验收结果) 为准。主要维护测试：

- `test_base_game_v1.py`：请求重放、状态回滚、自动/手动存档、资源边界、条件抵消、武器/法术共享状态、敌对结局。
- `test_adventure_acceptance.py`、`test_exploration_story.py`：三职业双路线，实际内容 XP、事件和奖励只结算一次。
- `test_progression_acceptance.py`、`test_adventure_lifecycle.py`：1–5 级资源、失败恢复、非法操作。
- `test_combat_commands.py`、`test_world_encounters.py`、`test_core_gameplay.py`：基础战斗、世界持久化、背包与恢复。

## 后续版本

AI 主持与开放探索、可视化模组编辑器、纯文本故事解析器、记忆/RAG、画布游戏呈现分别按完整版本定义和验收。当前不新增空壳接口来冒充这些能力已实现。
