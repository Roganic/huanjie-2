# DND 5e MVP 提炼

阅读顺序：先看“结论摘要”和“推荐保留”，需要继续细化时再看“暂不纳入”和“数据落点”。

本文件不是 5e 原文摘录，而是面向 AI 跑团第一版规则内核的提炼结果。

## 结论摘要

- 5e 最值得吸收的不是完整职业与法术体系，而是玩家熟悉的判定语言。
- MVP 可以保留 `d20 + 属性调整值 + 熟练加值 vs DC` 这一核心结构。
- 优势 / 劣势应直接保留，因为它比大量细碎修正值更容易被模型和玩家共同理解。
- 战斗层先保留 AC、HP、先攻、移动、动作、附赠动作四块；反应和复杂特例延后。
- 技能、专长、子职业、法术细则不应在第一版直接照搬，否则规则边界会迅速失控。

## 适用范围

- 用于收敛 `docs/rules-core.md` 中“轻量 d20 体系”的具体参考来源
- 用于后续设计结构化规则数据格式
- 用于判断哪些 5e 元素适合进入本地 Web 原型和规则引擎

## 推荐保留

### 1. 属性与调整值

- 保留六属性框架：力量、敏捷、体质、智力、感知、魅力
- 保留属性调整值概念，方便兼容玩家认知
- MVP 不急着完整复制点购、标准数组、种族修正等角色构建流程

原因：

- 六属性是 5e 最稳定的认知接口
- 对 AI 判定和 UI 展示都足够简洁

### 2. 统一检定语言

- 使用 `d20 + 属性调整值 + 熟练加值`
- 将豁免、技能检定、通用属性检定统一视作同一判定框架的不同标签
- DC 采用少量稳定档位，而不是过度依赖自由裁量文本

建议的 MVP DC 档位：

- 10：简单
- 15：中等
- 20：困难

难度描述完成这件事有多难；失败风险和代价另行设定，不用“高风险”代替高 DC。

原因：

- 玩家容易理解
- 后端裁定逻辑简单
- 便于日志记录和调试

### 3. 熟练系统

- 保留“熟练 / 不熟练”的二元区分
- MVP 中熟练加值可采用统一成长，先不处理来源差异
- 技能列表可以保留为能力标签集合，但不必一开始做满 5e 全表

原因：

- 熟练提供了角色差异化的最低成本方案
- 比复杂技能树更适合第一版实现

### 4. 优势 / 劣势

- 原样保留优势 / 劣势
- 不叠加多层数值修正，优先折算为是否具有优势 / 劣势
- 互相抵消后回到普通检定

原因：

- 这是 5e 最适合 AI 跑团的机制之一
- 叙事条件可以比较自然地映射成裁定结果

### 5. 战斗基础骨架

- 保留先攻
- 保留 AC 与命中判定
- 保留 HP 与伤害掷骰
- 保留“每回合一次动作、一次移动”的回合骨架
- 是否保留附赠动作，应视职业和能力模块何时引入决定；若前期角色模板很少，可以先保留字段但少量使用

原因：

- 这部分已经足够支撑最小战斗闭环
- 再往上增加复杂度，主要收益来自职业与法术模块，而非基础战斗本身

## 可压缩保留

这些内容有价值，但应以“简化版”进入 MVP，而不是完整复刻：

- 技能列表：先保留高频技能标签，不强求一次齐全
- 状态效果：先做少量高频状态，如受限、倒地、隐匿不利
- 装备：先保留武器伤害、护甲 AC、少量关键标签
- 法术：如果需要法术角色，先做少量模板化法术，不直接搬运完整法术库

## 暂不纳入

- 复杂职业资源循环
- 多层特性联动
- 细碎例外条款
- 复杂反应体系
- 擒抱、推搡、借机攻击等高争议战斗特例
- 完整法术组件、施法位、专注边角案例
- 大而全的怪物特性文本

判断标准：

- 如果一个机制严重依赖例外文本解释，就不应进入 MVP 基础层
- 如果一个机制不能被稳定结构化表示，就先留在后续模块

## 对 AI 跑团的实际价值

5e 对本项目最大的贡献有三点：

- 提供玩家天然熟悉的输入语言
- 提供统一而可结构化的检定模型
- 提供优势 / 劣势这种适合叙事裁定的中间层机制

5e 不应直接成为本项目的实现上限。第一版更像“借用 5e 语法，压缩成 AI 可执行规则核”。

## 数据落点建议

如果后续要做结构化规则数据，5e MVP 提炼结果可以先映射为以下对象：

- `ability_scores`
- `ability_modifiers`
- `proficiencies`
- `check_context`
- `advantage_state`
- `combat_stats`
- `action_budget`
- `condition_tags`

这意味着后端优先围绕“统一判定”和“战斗最小闭环”建模，而不是围绕完整职业文本建模。

## 与规则内核的关系

对 `docs/rules-core.md` 的具体支撑可以概括为：

- “轻量 d20 体系”对应统一 d20 判定框架
- “吸收 5e 的玩家认知优势”主要指六属性、熟练、优势 / 劣势、基础战斗语法
- 不等于完整采纳 5e 的职业、法术和例外规则
