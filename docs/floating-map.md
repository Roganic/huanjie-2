# 方格地图浮窗与友方保护

2026-09-07 用户调整当前范围：暂停攻击友方/中立人物，未来将人物敌对、剧情分支、物品与关键线索掉落一起设计；地图改为可移动、调整大小的半透明方格浮窗。本次沿用现有 React 和内容出口数据，没有引入空间战斗规则或新的渲染依赖。

## 使用方式

- 点击顶部“地图”打开，再次点击或点击浮窗 × 关闭；浮窗获得焦点时也可按 Esc 关闭。
- 拖动标题移动窗口，拖动右下角调整窗口大小；标题旁 − / ＋ 可直接缩小/放大窗口。位置和尺寸保存在本地，下次打开仍保留；窗口改变时自动限制在屏幕范围内。
- 比例滑杆改变地图缩放；放大后可在图内滚动查看。“定位”返回当前位置。
- 小方格表示地点，金色立体箭头标记当前位置，自动旋转并上下浮动；底部可手动旋转或暂停动画。系统减少动态效果偏好会关闭自动动画。
- 相邻可达地点用绿色边框、连线与方向文字标出；点击地点后选择“前往此处”。非相邻地点只能查看，不能通过地图越过出口限制；战斗/失败状态可查看地图，不能移动。
- 已探索地点保留名称，尚未探索且不相邻的地点显示未知。地图是出口连接示意，方格距离和摆放不用于战斗判定。单向出口仍按当前场景的实际出口判断可达性。
- 浮窗不会给游戏加遮罩，窗口外的交谈和其他界面操作仍可使用。

## 友方攻击边界

`game/targeting.py` 提供统一目标权限边界。友方与中立人物不能被新攻击变为敌人；直接战斗接口、文字动作、攻击法术和 `/commands` 都在开始遭遇前检查。拒绝不消耗时间/资源、不使任务失败、不生成结局与掉落。探索界面不再提供攻击和平人物的按钮。

此前存档中已经成为敌人的人物继续按敌对状态处理，已有战斗和结局不重置。旧敌对状态的恢复测试保留。后续剧情敌对系统可扩展这一边界，当前没有把编辑器、掉落脚本或复杂剧情转折提前加入。

## 实现与验证

- `MapPanel.tsx`：非模态浮窗、Pointer Events 拖动与拉伸、键盘支持、窗口偏好、过期地图防护、选择与移动。
- `mapLayout.ts`：按内容出口生成稳定方格位置；处理位置碰撞与断开场景，不改变实际出口或内容数据。
- `FloatingMap.css`：独立透明地图样式与 CSS 立体箭头。原列表地图样式已清理，共享背包弹窗样式保留。
- 后端 **671 项测试通过，0 失败/跳过**；其中 11 项新增目标权限测试覆盖友方/中立、接口/命令/文字/法术/SSE、任务与资源不变。旧主动攻击和平 NPC 的断言已按新要求更新；已敌对存档兼容检查仍保留。
- 前端 TypeScript、生产构建与 lint 通过。
- 隔离浏览器实测：拖动、鼠标拉伸、尺寸按钮、相邻地图移动后当前位置更新、非相邻不可移动、窗口外交谈、友方攻击中文拒绝、暂停动画、Esc 关闭、重新打开与尺寸位置保留。
- 375、768、1024、1440 像素宽度下检查浮窗边界；375 下文档无横向溢出。缩放图内容可滚动，浮窗关闭和尺寸控制始终可访问。最终浏览器未记录脚本错误。

本地试玩采用 5174/8001 与独立测试存储，未修改用户游戏进度；交付页面继续使用 5173/8000。当前政策和地图呈现对已有会话生效，不要求启动新冒险。
