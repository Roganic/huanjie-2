# 模型费用保护

本轮项目 API 总预算 50 元。当前采用分配额度控制：本地开发最多 20 元，Sites 服务端最多 25 元，另留 5 元对账余量。2026-09-09 网站累计阈值目前为 5 元（首发为 2 元）；本地筛选与创作验证的累计阈值由 2 元调至 6 元，以覆盖更强模型的受限对照。原账本及未确认费用预留全部保留，没有重置累计值。两个账本不会各自获得完整预算。

## 结算方式

- 请求发出前，按完整请求的 UTF-8 字节量及协议余量估算输入上界，加上允许的最大输出量，预留费用。
- 模型返回有效 usage 后，按已核验的官方未缓存价格记录；思考模型同时计入思考输出费用。回答违反游戏格式也照常记账。
- 超时、断线、无 usage 或无法判定的错误保留整笔预留，不假设免费；后续人工核对供应商账单。
- SQLite / D1 的原子写入将并发、重试和解析修复计算在同一运行环境的总额内。更换模型不清空账本。
- 未核验价格的模型、超过已核验上下文范围的请求、非法阈值和预算不足的请求在联网前拒绝。

本地账本为后端 `.model-usage.sqlite`，不进入 Git、游戏存档或发布包。网站使用服务端 D1 `model_usage` 表，玩家无法通过刷新、换账号或请求体重置预算。隔离云端模拟器默认不允许付费请求，避免换一次测试目录就获得一笔新额度。

这是一层保守的应用费用控制，不代替供应商账单，也不能约束同账号其他应用的请求。未知计费、缺失用量和运营商调价都需要对账；不会把未使用的套餐额度自动视作零成本，也不会自动充值或订阅。

Qwen3.7 Plus 输入/输出每百万 tokens 为 2/8 元（北京、短上下文，未应用活动或缓存折扣）；该模型思考与最终回答使用相同输出单价。普通游戏请求保持非思考模式；模组创作使用最多 4096 tokens 的有界思考，请求前将该上限额外计入预留，避免只计算最终回答。超时未返回 usage 仍保留整笔费用。旧 GLM-4-Flash 为免费候选，但其语义质量未通过。其他模型需先核验价格后加入计费表。参考 [百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[思考参数说明](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)。
