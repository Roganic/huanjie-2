# 最后一盏渡灯

短篇模组 · 约 20–40 分钟 · 1 名低等级角色 · 调查、交涉与救援，无强制战斗。

## 故事

暮潮港的最后一班渡船载着七个人，其中有一名发着高烧的孩子。雾在入夜前压低，导航灯却只剩一圈红色的余烬。守灯人岑婆把一张潮汐纸摊在你的掌心：“亮灯，或者敲出正确的钟声。船上的人不能等我们追究谁的错。”

灯塔的聚光镜并没有被偷走。修灯学徒阿禾发现镜框裂开，擅自拆下加固，又怕承认自己弄断了一颗螺栓，将维修记录藏了起来。送油人早早离开，众人便把嫌疑推给了他。阿禾的沉默不是恶意；他相信只要在师父发现前修好，就不算犯错。

玩家可以安抚阿禾，让他交出校准图；也可以去潮阶查看维修匣。检定失败不会堵死故事：潮水会打湿图纸、耗去时间，但匣盖的浮雕仍能让玩家花更多时间复原操作顺序。

回到灯塔，持有校准信息就能稳妥调整灯光。没有修灯条件时，玩家可依照岑婆提供的潮汐纸敲出三短一长的渡钟，指引渡船靠近避风的小码头。这条路线同样救下乘客，却意味着货物被海水浸坏。若拖延到浓雾完全封港，救援仍能完成，只是船必须等待拖船协助。

结尾，阿禾主动站到岑婆面前。玩家若找到维修记录，便能证明送油人清白。岑婆没有立刻原谅学徒，却把旧螺栓交给他：“明天开始，你学的第一件事是求助。”

## 地点与人物

- 渡口：岑婆交代救援任务、提供钟声路线，最后在此提交结果。
- 修灯棚：阿禾回避错误；交涉成功提供校准图，失败后仍可交谈并去潮阶查证。
- 潮阶：维修匣调查成功得到记录与校准信息；失败产生湿纸线索，可花时间复原。
- 灯塔：调整灯光或敲钟引航；两种明确操作都不会无故掷骰。

## 可玩规则

与岑婆交谈接取“让渡船回家”。交涉与调查采用 DC 10 鉴定，有明确成败后果。查看/移动/引航按规则自动结算。雾封港事件在接取后 10 格时间到期；完成引航后取消，不直接处死乘客。

结局按已结算事实选取：及时亮灯“雾里的光”；使用钟声“听见归航”；延误后救援“等到天亮”。找到维修记录可为后续对白提供真实证据，不能凭空发放奖励。完成救援并向岑婆报告得到 80 经验与渡口纪念章。

## 试玩路线

成功：岑婆 → 修灯棚交涉 → 灯塔校准 → 渡口报告。

失败推进：岑婆 → 潮阶调查失败 → 复原湿纸 → 灯塔校准 → 渡口报告。

免检定备选：岑婆 → 灯塔敲钟 → 渡口报告。
