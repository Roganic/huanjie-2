# 第二阶段：完整 AI 冒险闭环

本阶段把自由表达、具体目标、检定后果、人物记忆、后续事件和任务结局连在一起。基础按钮继续直接执行规则；模型负责理解做法、选择合法方案和承接对白。样例冒险为 **余烬钟声**，从“菜单 → 模组 → 余烬钟声 → 以此模组开始新冒险”进入；旧冒险保留自己的内容快照。

## 玩家体验

| 输入或选择 | 实际处理 |
| --- | --- |
| 表达不满、赞叹或姿态，没有具体诉求 | 表达，不掷骰、不扣时间、不触发委托或好感奖励 |
| 问人物已有消息 | 普通交谈；从人物知识和既有事实回答 |
| 查询背包、角色或已接任务 | 通过只读能力查询真实数据，不替换成装备或其他动作 |
| 争取支援、核实证言等具体目标 | 匹配目标契约，确定做法和后果，再由程序检定 |
| 目标结果确定，只需要付出时间 | 执行自动挑战，不额外掷骰 |
| 失败后换一句话或换技能再试 | 检查同一目标的机会、相关线索或等待条件 |
| 对同一人物提出另一个目标 | 单独检查该目标，不连带锁住人物的其他互动 |
| 模型把实际操作选成聊天 | 类型校验拦截，最多一次规划纠正，仍不一致则不执行 |

“普通表达”不是攻击或强迫行为的豁免入口。攻击仍提交实际攻击意图，友方／中立保护继续由底层执行。无规则支持的要求需要澄清或明确不能执行。

## 冒险内容与结局

余烬钟声包含暮钟广场、旧档案室、芦苇河岸、匪徒营地四个地点，三位和平人物、两名敌人。

- **交涉**：向伊莲争取支援，可以选择药水或鼓舞；再以另一项目标核实证言，取得报告依据。
- **档案调查**：核对页码或辨识记号。失败会受伤、解锁副本，并安排烟尘后果；整理副本不再掷骰，但需要付出时间。
- **河岸调查**：根据船痕或说服船夫核实航线。失败仍明确营地路线。
- **战斗**：进入营地即与两名敌人遭遇，使用已有先攻、职业能力和战斗规则；清理后返回报告。
- **时间推进**：接取委托后搜索队等待八格世界时间；超时影响伊莲态度。提前取得报告依据或清理归路会取消该后果。查看界面或普通问话不推进时钟。
- **结局**：调查报告、失败后找到副本、清理归路分别形成持久结局；奖励只能结算一次。调查结局不会凭空消灭营地敌人。

## 共用契约与未来编辑接口

继续扩展现有 `ChallengeDefinition`，没有另造一套剧情规则引擎。模组 JSON、未来编辑器、未来文本解析器、按钮和 AI 共用同一份 Schema。

| 字段 | 用途 |
| --- | --- |
| `goal_id` | 同场景、同目标对象的稳定目标编号；不使用玩家原话作为重试键 |
| `approaches` | 允许的做法、技能、难度与前置条件 |
| `consequences` | 完整成败后果包的可选组合；不向模型开放任意事件参数 |
| `retry_flags` | 只有指定剧情条件变化可以重开；空数组表示无此类重开条件；未设置保留旧契约语义 |
| `completed_flags` / `complete_on_success` | 与其他路线共同完成目标，或成功后永久关闭该机会 |
| `retry` / `retry_delay` | 一次机会、条件变化、付费再试或时间间隔；一次机会不能配置倒计时重开 |

同一 `goal_id` 的多个契约必须共用重试与完成政策，防止通过换契约绕过限制。通用社交的四种技能仍属于同一“影响态度”目标；它不代替具体的物品、线索或任务请求。

模型的 `adjudicate` 使用平铺的 `approach_id`、`consequence_id`，适配工具调用；普通动作 `act` 必须声明 `intent_kind` 和 `goal`。按钮的 `/commands` 使用 `choice: {approach_id, consequence_id}`。空选项与未选项等价；未知 ID、未解锁选项和额外数值字段拒绝。

程序在掷骰前复制完整契约，校验做法、前置条件、成败两套事件及实体引用，然后执行一次。模型不能在看到骰点后换奖励。实际事件继续通过关系、物品、状态、线索、标记和遭遇等已有服务落地；原子回执保证重放不重掷、不重复发奖。

参考：`app/backend/src/models/adjudication.py`、`src/game/adjudication.py`、[模组 Schema](module.schema.json)、`app/backend/src/content/adventures/ember-watch.json`。

## 记忆与主持职责

- `npc_memories` 为每位人物保存最多 12 条已执行互动：玩家当时意图、真实结算、目标、成败、检定、关系和时间。玩家意图明确标为非事实。
- 目标完成与重试记录独立持久化，不随近期聊天窗口被裁剪；当前关系、线索、任务、事件及人物条件知识继续作为权威来源。
- 规划读取当前能力、结构化记忆和最近两段短对白；叙事优先取近期目标结算、当前人物记忆和最近两段实际对白。旧对白仅用于对话衔接，不能反过来修改游戏事实。
- 行动规划和叙事使用独立提示；最新输入与本轮裁定放在当前上下文之后，避免长历史掩盖本轮主题。
- 模型请求期间不锁住游戏；提交前复核版本。规则结果先保存，之后才补写模型对白。断线、模型超时或降级不会回滚已执行结果。
- 仍采用现有有界工具循环：每轮最多四次模型调用、两次查询、一次实际行动，最多一次意图类型纠正，总等待预算 35 秒。常规按钮不进入模型规划。

## 验收与边界

当前功能开发与游戏层验收完成；模型服务部分请求返回使用资格错误，连续纯 AI 验收尚未完成。规则回归、真实模型路线和网页验收记录见 [本轮记录](sessions/2026-09-08-phase2-adventure.md)。验收使用独立角色、会话和存档；随机值固定仅用于覆盖指定成功/失败路线，真实游戏不固定骰点。

本阶段交付的是内容契约约束下的 AI 冒险。模型可以理解不同表达并组合允许做法与后果；尚未开放任意生成新人物、地图、装备、任务和规则。语义理解与对白质量仍受所配置模型影响，格式校验不是完整的语义证明。权限、数值、进度与存档由程序控制。

下一大阶段是模组创作系统：先可视化编辑与预览，再把纯文本解析为可审核的模组草稿；两者复用这里的契约。游戏渲染框架升级单独评估。
