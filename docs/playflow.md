# 冒险状态、战败恢复与简化成长

2026-09-06：本批完成战败后的继续入口、共享行动限制和三职业 1–5 级成长验收。后端全量 **633 项通过，0 失败/跳过**；前端构建与 lint 通过。解析器和编辑器继续只保留接口，没有接入真实模型。

## 状态与继续方式

`game/lifecycle.py` 从角色、战斗快照和冒险阶段派生 `play_status`，通过 bootstrap 和成长接口提供给前端；执行操作时服务端再次校验。

| 状态 | 玩家可以做什么 |
| --- | --- |
| 建角 | 创建角色后开始冒险 |
| 探索 | 移动、交谈、调查、管理背包、使用恢复能力；场景没有存活敌人才可休息 |
| 战斗 | 使用战斗命令或撤退；禁止跨场景移动、休息及探索背包操作 |
| 战后结算 | 查看结果并返回探索，再执行探索操作 |
| 战败 | 查看原因和历史、读取存档、重新冒险；不能移动、休息或用药水复活 |

已有角色的保存、读取与查看信息不作为探索行动。保存支持战斗快照。旧存档即使错误地保留探索阶段，只要 HP 为 0，也会判定为战败。

- 战斗击倒记录敌人和地点；场景效果致命同样结束冒险并保留原因。旧记录缺少原因时，只说明生命值耗尽，不补造击倒者。
- 放弃战斗会将生命值设为 0 并结束本次冒险。重复退出不会解除战败。
- **读取存档继续**恢复存档时的状态；读取战败存档仍然是战败。
- **重新冒险**调用 `POST /session/restart`，创建独立会话，沿用姓名、职业、属性与当前固定内容包，从 1 级起点开始，物品与任务进度重新初始化。原会话和手动存档保留；战斗进行中拒绝重新冒险。
- 首版采用直接失败，不包含濒死豁免、复活或死亡惩罚经济系统。

## 行动与资源

文字和按钮的休息共用同一服务；背包、移动、交谈等入口读取统一状态限制。行动如不满足阶段、目标或资源条件，返回明确原因，不扣除资源。

和平场景中的攻击法术必须指向真实 NPC，随后进入现有遭遇和先攻流程；开始遭遇本身不造成法术伤害、不消耗法术位。动作如潮、佯攻、躲藏、防御、结束回合、撤退只在战斗中执行。回气和治疗法术可在探索中恢复伤势，满血时拒绝无效消耗。

本阶段时间采用抽象 tick：地图移动、成功使用药水或探索治疗各 1，短休 1、长休 8；普通交谈、拾取和穿脱装备不消耗时间。战斗中每个成功玩家命令及其敌方响应作为一次推进。场景检定按既有互动规则推进，失败仍可产生后果，已完成的一次性互动不重复结算。tick 不代表现实小时，食物、负重与疲劳压力尚未实现。

## 支持 1–5 级

适用职业为战士、盗贼、法师，经验阈值分别为 0、300、900、2700、6500。5 级后经验继续累计，等级保持 5；界面显示支持范围，不承诺完整原版职业树。

- 1 级生命上限为生命骰最大值加体质修正，最低 1；之后每级增加生命骰的一半加 1、再加体质修正，最低增加 1。
- 1–4 级熟练加值为 +2，5 级为 +3；技能熟练加值随等级重算，生命骰总数等于等级。
- 战斗奖励升级会同步生命上限、当前生命、生命骰及法师法术位；战利品保留。职业能力的恢复仍走对应休息规则。
- 不自动增加属性分配、专长、技能学习树或完整职业构筑。
