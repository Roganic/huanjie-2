# 产品定义

阅读顺序：先看“当前目标”和“当前范围”，只有在需要推进产品决策时再补充细节。

## 当前目标

构建一个 AI 跑团系统的本地 Web 原型，验证以下问题：

- AI 是否能稳定担任 GM
- 规则内核是否足够简单但仍然好玩
- 记忆 / RAG / 规则引擎的组合是否可行
- 多轮长流程体验是否成立

## 当前范围

- 单个项目工作区
- 本地 Web 原型
- 文档优先推进
- 规则研究与实现并行

## 暂不做

- 多端 App
- 多服务复杂拆分
- 完整复刻任意一套原版规则
- 过早追求完备美术、世界观资产或上线级基础设施
