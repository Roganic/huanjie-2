# 探索定位与普通 NPC 交谈

## 目标与输入

用户反馈不知道自己在哪、接下来做什么；输入“和老马库斯说句话”后出现英文与力量检定。问题在于普通交谈落入通用规则和占位叙事，且“打招呼”含有旧战斗关键词“打”。

## 实现结果

- `game/exploration.py` 提供普通交谈与探索建议，`/action` 在探索阶段优先处理会话中实际在场的 NPC；不调用模型、不掷骰、不改变 HP/XP、不触发战斗。
- 原始输入“说句话”、“说话”、“询问消息”和“打招呼”均覆盖 JSON 与 SSE。对象缺失、歧义或暂未实现的特殊社交明确返回中文提示，不授予线索。
- 根据已有场景和人物写入轻量固定内容：老马库斯指出酒馆东边的地下城入口和托尔金；托尔金提醒地下城的哥布林危险与装备、补给准备。其余友好/中立角色提供基本建议，尸体与敌对 NPC 不出现普通交谈按钮。
- `SessionData.discovered_clues` 是线索权威状态，完整会话快照自动包含它，旧存档默认空值；新建角色重置线索及对话。重复交谈只提醒已知内容，不重复生成线索或奖励。
- `/exploration` 返回地点、建议、NPC、合法相邻出口和已知线索。前端直接嵌入主界面，随状态刷新；移动按钮使用已有权威移动接口。此建议不是新增主线任务或强制路线。
- 修复叙事区过滤系统通知导致“抵达”和操作错误不可见的问题；行动历史不再把无检定失败一概标为自动成功，不再添加空白场景/GM 提示。
