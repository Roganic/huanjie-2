# 全场遭遇与任务闭环实施

## 输入与取舍

用户同意增加遭遇、战后场景与任务后果，并明确允许攻击和平 NPC；取消站位、距离、警戒、察觉，遭遇内全部敌人参战。正式规则见 [场景与遭遇](../world-encounters.md)。此批沿用 React 和固定内容，不接入模型。

和平 NPC 被攻击后仅该 NPC 转为敌对；与场景原有敌人一起参加先攻，其他和平人物不自动敌对。速度使用敏捷修正，先攻 d20＋速度；同值先比较速度，再玩家优先、敌人固定 ID。攻击宣告本身不产生免费伤害。

## 实现

- 新增 `models/world.py` 与 `game/world.py` 保存各地敌人的完整属性、HP、敌对及奖励记录，提供场景视图、移动触发和托尔金委托。
- `combat_service` 改为多敌人权威状态，支持指定目标、跳过死亡者、全员先攻、撤退返回来路及清理后不重生。兼容旧单敌人快照直到该战斗结束。
- 胜利结算将 XP、战利品、奖励标记、场景清理、任务状态及战斗快照一并保存，避免中途先持久化 XP 而漏掉领奖标记。
- 普通敌人战斗奖励一次；主动攻击的和平人物不生成 XP/随机战利品。撤退不领奖但保留敌人伤势。
- 托尔金委托支持接取、清理全部敌人、回报领取两瓶药水、完成及攻击委托人导致中止。主界面直接展示真实状态，旧模组空任务栏不再宣称没有基础任务。
- 移动文本和按钮共用世界移动入口，攻击文本和按钮共用遭遇入口。普通对话优先于移动识别，继续覆盖“说句话”和“打招呼”，不会误触战斗。
- 战斗取消隐匿/被动察觉对抗，盗贼改为“佯攻”，消耗附赠动作获得下次攻击优势。能力文本选择敌人时仍能对自身使用回气等能力。
- 界面显示和平/危险/已清理、现存敌人数、出口遭遇人数、明确的 NPC 攻击入口和先攻骰/速度/总值，不包含站位。
