# 充值后的阶段对齐与 API 套餐调查

## 最新补充复核

用户再次要求对齐阶段并由子 agent 调查其他 API 套餐。继续使用 `api_packages` 子 agent 做只读官方资料复核，未购买、切换配置或因本次调查新增付费请求。

- 阿里：官方仍列举 10 元抵 20 元、27 元抵 60 元；后者分三个月发放。已有充值不代表具有首购资格，也不等于购买该计划。
- 火山：50 元月度钱包有首次五折宣传，25 元成交价仅是推算，未取得动态订单价。
- 智谱：官方价格页列出 GLM-4.7-FlashX 每百万输入 0.5 元、输出 3 元。假设 800 万输入和 130 万输出，则为 7.90 元，仅是用量情景测算，不是项目实测费用或质量证明。
- DeepSeek、硅基流动未查到足以支持迁移的、可确认的小预算通用套餐；不将未查到表述为不存在。

当前建议：继续用已充值百炼完成质量验收；有实际需求再核验小额抵扣包，智谱保留备选。阶段交付与当前进度以 `docs/release-plan.md` 最新摘要为准。下文为最初调查记录，其“尚未实施”仅描述当时状态。

用户确认已充值，要求先对齐后续阶段，并明确授权一个子 agent 调查其他 API 套餐。主 agent 更新 TASKS 和 release-plan，子 agent 只读调查官方资料；没有购买、切换配置或启动付费调用。

先验证已充值百炼的模型质量。真正可供游戏后端使用的节省计划存在，但小预算不应只为宣传额度迁移。套餐优惠不能证明模型叙事、工具选择和故事解析合格。
