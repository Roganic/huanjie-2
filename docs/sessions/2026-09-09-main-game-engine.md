# 游戏主界面迁入引擎

本轮把主界面从 React 页面状态树迁入 Phaser Scene。不是只把地图放进 Canvas：创建角色、探索/战斗切换、地图镜头、敌人选择、主操作、叙事与规则记录、菜单、保存恢复和终章展示都由冒险 Scene 生命周期组织。React 仅保留背包、模型设置、模组库和创作工坊这些辅助表单。

## 实现边界

- `game/controller.ts` 是唯一主会话/刷新/命令控制器，继续走原有 `gameFetch` 与后端命令、裁定和存档，不另建规则系统。同步失败先锁定新行动；来自背包的在途请求也在关闭面板后继续显示状态和恢复入口。
- `game/adventureEngine.ts` 管理场景、Canvas 地图和战斗先攻队列。`game/interface.ts` 是 Scene 创建/销毁的原生语义文字和输入层，长篇中文、键盘操作及表单不画成无法访问的位图。
- 原约 3,400 行 `App.tsx` 主页面替换为辅助面板宿主。旧 App/PlayLayout 样式不再加载；构建 CSS 从约 100.6 KB 减至 30.7 KB。Phaser 带来约 406 KB gzip 的主脚本，仍有构建体积提示，不能声称首屏已极致优化。
- 保留不规则节点路网、相邻路线、定位/缩放、可旋转上下浮动的当前地点标记；地图可归位、浮窗、拖动/方向键移动、浏览器原生拉伸、关闭与重开。窗口位置暂不跨刷新保存。
- 保留职业与属性生成、技能/成长/法术位、背包、检定前的做法与后果选择、任务/线索/事件手记、先攻与战斗行动、战败/终章和继续冒险。
- 新玩家经 `/state/bootstrap` 创建独立会话；已有会话继续原进度。兼容 `/state` 的法术位字典。按钮行动不会把 `talk` 等内部命令名显示成玩家说的话。
