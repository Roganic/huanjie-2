# 预设模组视觉样板：本地交付

用户明确本轮只做本地部署和测试，不发布 Sites。延续现有玩法与 Phaser 场景生命周期，以灯笼酒馆与地下城七个地点完成连贯视觉样板。

## 改动

- 新增九张原创素材，七个地点各有匹配的场景图；酒馆三位 NPC 肖像可以直接交谈。
- 统一角色档案、场景画框、纸页叙事、地图、战斗配色和排版；保留属性、装备、目标、人物与相邻地点信息。
- 地图从拥挤的默认节点排布改为预设构图，实际出口绘制道路；增加标签安全边距，平板地图最低高度避免三排地点重叠。
- 手机先攻队列采用双列，行动按钮三列，修复操作被截断；动作区和正文各自滚动，输入保持在可用区域。
- 视觉契约增加受限内置素材名与可选地图版面坐标。旧默认存档采用只读视觉补足，已有自定义皮肤不被覆盖。封面与编辑器继续支持内置图、上传覆盖和焦点。

## 验收证据

- 本地地址：`http://127.0.0.1:5173/`，原生后端：`127.0.0.1:8000`，使用持久会话启动方式。
- 浏览器真实创建测试角色“艾林”，通过酒馆肖像进行一次真实模型交谈；移动到地下城通道，三名敌人进入同一先攻，普通攻击造成真实伤害，随后撤退并继续探索。
- 通过真实相邻地点按钮访问地下城入口、宝库、古庙、村庄、森林和酒馆；危险地点仍触发原有遭遇，验收中按现有撤退流程退出，没有为了截图绕过规则。
- 地图浮窗由 `(24,130,560,520)` 拖动为 `(154,220,560,520)`，实际拉伸至 `653×583`；缩放、旋转指针、关闭及重开通过。
- 桌面 1440×1000、平板 1024×768、手机 390×844 的探索和战斗截图已检查，无页面横向溢出，无浏览器脚本异常。手机地图单独打开检查通过。
- 长文使用仅替换浏览器响应的“排版验收样文”，未写入存档或调用模型；先断言样文实际存在，再检查 243 像素阅读区可滚动 1786 像素内容，输入仍在屏幕内。另已检查真实旅途多条记录。
- 相关后端检查 21 项通过（视觉契约、预设冒险、地图）；最后封面调整后再次运行视觉检查 7 项通过。前端构建和 lint 通过。未重复运行无关的全量旧测试。
- 构建仍提示包含 Phaser 的主包较大（约 1.49 MB，gzip 413 KB），本轮没有声称已完成资源加载与包体优化。
