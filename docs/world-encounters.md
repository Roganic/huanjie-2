# 场景、遭遇和基础任务

> 当前规则更新（2026-09-07）：友方/中立攻击暂时禁用；此前已有的敌对存档保留。地图已升级为透明方格浮窗，当前全量 671 项通过。以下原版本记录中的主动攻击和平人物/新达成敌对结局不再是当前可用入口，详见 [地图与友方保护](floating-map.md)。

## 已确认规则

用户于 2026-09-06 确认：增加场景遭遇，允许攻击和平 NPC；攻击后场景升级为危险。取消站位、距离、警戒与察觉；触发遭遇后全部敌人参战。战后状态持久化并推动任务。

## 当前实现

- 场景显示和平、危险或已清理。进入有存活敌人的地点，全部敌人立即参战；出口预告敌人数。首版使用场景已有敌人列表的固定遭遇，替代未接通的随机遭遇概率。
- 地下城通道有哥布林斥候、哥布林萨满和座狼，共 3 名敌人；森林 1 名、古庙 2 名、宝库 1 名。只有原本敌对或被玩家攻击的人物参与战斗，其他和平人物不会自动敌对。
- 攻击和平 NPC 必须指定在场且存活的目标。先加入敌人列表、永久记录此处发生过攻击，再进入先攻；发动攻击没有免费伤害。尸体不可作为新战斗目标。
- 速度＝敏捷修正，先攻＝d20＋速度。按先攻降序，平手速度高者先，再平手玩家先，敌人按稳定 ID 排序。每次新遭遇掷一次，同一战斗读档或重复开始不会重掷。
- 每个存活敌人按先攻执行一次动作，死亡单位跳过。玩家选择任意存活敌人作为攻击目标，单体能力不进行射程检查。现有伤害法术仍按单目标结算，群体法术扩展不在本批范围。
- 玩家回合的主动作、附赠动作、职业资源仍使用原有预算。盗贼“隐匿”替换为“佯攻”：附赠动作获得下次攻击优势、命中可偷袭，不做察觉检定；旧 `hide` 命令映射为佯攻。
- 撤退不领奖，返回进入该地点前的位置。如果旧存档或直接载入场景没有来路，结束遭遇后留在当前地点，允许从合法出口离开。敌人 HP 和死亡状态保留，再进入时只有存活敌人参加。
- 普通敌人全部击败后发放本场 XP/战利品一次，场景清理且不重生。主动攻击的和平 NPC 不提供 XP 或随机战利品。因攻击和平 NPC 而变危险的场景即使清场仍保留危险标记；未实现关系修复。
- 地点仍有敌人时不能休息；死亡角色仍需读取此前存档或新建角色，复活规则不属于本批。

## 第一条可玩委托

内置 1.0.2 已将此委托扩展为“地下城通道的隐患”，增加调查入口、回村示警的非战斗路线；旧冒险维持原内容。新规则见 [探索闭环](exploration-story.md)，下文为原清场路线。

托尔金的“清理地下城通道”：普通交谈接取 → 击败通道全部敌人 → 回入口交谈报告 → 获得治疗药水 ×2。状态为待接取、进行中、待交付、已完成或已中止。奖励只发一次，读档保留。攻击托尔金会中止未完成委托；已完成的委托保持完成。

这是一条固定基础委托，不代表模组任务系统已全面接通。已有托尔金线索的旧会话可继续该委托。

## 接口与存档

- `GET /exploration` 返回场景危险状态、现存敌人数、NPC 目标、合法出口、线索和委托。
- `POST /map/move` 与文字移动都调用 `world.move_to`，返回新遭遇信息。
- `POST /combat/start {target_id?}`：指定目标发动攻击；不指定目标时仅允许开启当前地点实际存在的敌人遭遇。
- `/action` 与 `/combat/action` 共享战斗命令处理；探索阶段的攻击只开启先攻，下一步才结算回合动作。
- `SessionData.world_scenes` 保存各场景敌人完整属性、HP、敌对及已奖励 ID，战斗快照保存先攻骰、速度、顺序、预算及撤退目的地，`passage_quest` 保存任务状态。
- 旧版本单敌人战斗快照继续按原有敌人及顺序完成，不在读档时插入新敌人。旧存档中没有场景清理记录的地点，按新规则首次生成；不能从历史叙事推断已清理。
